# 刷单词 WordsPrint

一个精致的**离线背单词 Android 应用**：以「整本课本」为单位刷词，覆盖中国主流教材版本。

## 词库（内置，零联网 · 精简版）
- **13 本词书 · 8,824 个单词**，只保留人教版：
  - 初中 5 册：七年级上/下、八年级上/下、九年级全（2,568 词）
  - 高中 7 册：必修第一/二/三册 + 选择性必修第一/二/三/四册（2,634 词，新课标）
  - 大纲 1 本：高考英语 3500 词（3,622 词）
- 每条词条：单词 + 国际音标 + 精简中文释义（打包为小端二进制 `res/raw/wdb.dat`，字符串池去重后 0.38MB）

## 核心玩法（按你的逻辑，做了细化）
1. 选书 → 自选**每组词数**（20/30/40/50/60/80/100/150，默认 50）
2. 选**刷词顺序**：课本顺序 / 随机打乱
3. 卡片正面只显示**英文**（+音标可选），点一下 3D 翻面显示**中文**
4. **记住了** → 该词永久划掉，不再出现；**不认识** → 进入回炉队列，
   每过 N 张（3/5/8 可选）再次出现，直到点「记住了」为止
5. 本组全部拿下 → 结算页（掌握数/正确率/用时）→ 一键下一组；整本刷完有专门庆祝页
6. 组指针自动续存：中途退出，下次从这一组继续；已记住的词永远跳过

## 进度跨设备迁移（v1.0.2 新增）
- 设置页 →「进度转移」：**导出二维码**（把全部 13 本书的掌握位图、组指针、每日打卡数压缩编码成一枚 QR）
- 另一台手机：同页面「扫码导入」→ 对准二维码，vibrate 确认后**合并**（掌握词取并集、进度取更大、打卡数取更大，不丢数据）
- 无摄像头/演示场景：导出页可**复制或分享纯文本码**，导入页「手动粘贴」同样生效
- 编码链路：自定义二进制格式 → Deflate → Base64URL → 自研 QR 编码器（EC-M，v1–40，
  `QREnc.java`）；每张导出图生成前用与扫码端同一套 zxing 做**自解码校验**，读不通就换掩码，
  保证「扫得到」；`test/QRHostTest` 对 92+500 个样本做渲染→解码→合并全链路断言

## 体验细节
- 首页：渐变 Hero + 今日已刷 / 连续打卡🔥 / 累计掌握；上次词书「继续刷」卡片；封面墙快速入口
- 词书库：搜索 + 全部/初中/高中/大纲 三档筛选，列表按学段分节，每本书带掌握进度条
- 底部弹层设置词数组（含已掌握「重刷整本」开关、回炉节奏）
- 沉浸式深色刷词页 + 纸感白卡；滑动左=不认识 右=记住了；记音：系统 TTS 自动朗读（无内置音频）
- ToneGenerator 轻音效 + 振动反馈；进度位图（BitSet+Base64）持久化到 SharedPreferences
- 自适应桌面图标（vector），minSdk 26 / target 34，APK 仅 **534KB**（含 ZXing 解码库）

## 构建
无 Gradle，纯 SDK 工具链：`scripts/etl.py` 产出 `res/raw/wdb.dat`，`./build.sh`（aapt2 → javac → d8 → zipalign → apksigner）。
主机侧测试：`test/PackTest`（数据格式解析）与 `test/EngineTest`（刷词引擎 6 组行为断言）直接编译发布用的同一份源码。

## 安装
`刷单词-v1.0.2.apk` 为自签名 debug 级证书包：传送到手机 → 允许「安装未知来源应用」→ 安装。
v1.0.1 → v1.0.2 可直接覆盖安装（同签名、versionCode 3），进度全部保留。
