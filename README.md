# 刷单词 WordsPrint

**当前版本：v2.10（dev）** <!-- CURRENT-VERSION -->

一个精致的**离线背单词 Android 应用**：以「整本课本」为单位刷词，覆盖中国主流教材版本。

## 词库（内置，零联网 · 精简版）
- **21 本词书 · 9,592 个单词**，只保留人教版：
  - 小学 8 册（PEP 三年级起点）：三~六年级上/下（768 词，`data/primary_words.tsv` → `scripts/etl_primary.py` 并入）
  - 初中 5 册：七年级上/下、八年级上/下、九年级全（2,568 词）
  - 高中 7 册：必修第一/二/三册 + 选择性必修第一/二/三/四册（2,634 词，新课标；词书库按**先必修后选修**排列）
  - 大纲 1 本：高考英语 3500 词（3,622 词）
- 每条词条：单词 + 国际音标 + 精简中文释义（打包为小端二进制 `res/raw/wdb.dat`，字符串池去重后 0.40MB）

## 核心玩法（按你的逻辑，做了细化）
1. 选书 → 自选**每组词数**（20/30/40/50/60/80/100/150，默认 50）
2. 选**刷词顺序**：课本顺序 / 随机打乱
3. 卡片正面只显示**英文**（+音标可选），点一下 3D 翻面显示**中文**
4. **记住了** → 该词永久划掉，不再出现；**不认识** → 进入回炉队列，
   每过 N 张（3/5/8 可选）再次出现，直到点「记住了」为止
5. 本组全部拿下 → 结算页（掌握数/正确率/用时）→ 一键下一组；整本刷完有专门庆祝页
6. 组指针自动续存：中途退出，下次从这一组继续；已记住的词永远跳过

## 进度跨设备迁移（v1.0.2 新增）
- 设置页 →「进度转移」：**导出二维码**（把全部 13 本书的掌握位图、组指针、每日打卡数压缩编码成一枚 QR）
- 另一台手机：同页面「扫码导入」→ 对准二维码，vibrate 确认后**合并**（掌握词取并集、进度取更大、打卡数取更大，不丢数据）
- 无摄像头/演示场景：导出页可**复制或分享纯文本码**（文本码常驻显示在码图下方，长按可全选；剪贴板被系统拒写时自动弹全文卡片兜底）
- 导入侧走 `ProgressCode` 容错解析：前缀可缺/大小写混在中文句子里、被折行、夹 NBSP/全角空格/零宽字符都照收；
  **复制被截断时，已写完整的部分照样合并**（并明确告诉你被截了）。设置页还有独立的「粘贴导入进度码」入口，完全不开摄像头
- 粘贴导入与相机彻底解耦（解析在子线程、释放相机在相机线程 + 同一把锁），避免 Camera1 release 抢 native 对象的进程级闪退
- 编码链路：自定义二进制格式 → Deflate → Base64URL → 自研 QR 编码器（EC-M，v1–40，
  `QREnc.java`）；每张导出图生成前用与扫码端同一套 zxing 做**自解码校验**，读不通就换掩码，
  保证「扫得到」；`test/QRHostTest` 对 92+500 个样本做渲染→解码→合并全链路断言

## 体验细节
- 首页：渐变 Hero + 今日已刷 / 连续打卡🔥 / 累计掌握；上次词书「继续刷」卡片；封面墙快速入口
- 词书库：搜索 + 全部/小学/初中/高中/大纲 筛选，列表按学段分节，每本书带掌握进度条
- 底部弹层设置词数组（含已掌握「重刷整本」开关、回炉节奏）
- 沉浸式深色刷词页 + 纸感白卡；滑动左=不认识 右=记住了；记音：系统 TTS 自动朗读（无内置音频）
- ToneGenerator 轻音效 + 振动反馈；进度位图（BitSet+Base64）持久化到 SharedPreferences
- 自适应桌面图标（vector），minSdk 26 / target 34，APK 仅 **534KB**（含 ZXing 解码库）

## 构建
无 Gradle，纯 SDK 工具链：`scripts/etl.py` 产出 `res/raw/wdb.dat`，`./build.sh`（aapt2 → javac → d8 → zipalign → apksigner）。
主机侧测试：**`bash scripts/run_tests.sh`**（本地与 CI 同一条命令，直接编译发版用的同一份源码）——
`PackTest`（数据格式解析）、`EngineTest`（刷词引擎 + 回炉区间断言）、`QRHostTest`（渲染→解码→合并全链路）、
`CodeHostTest`（进度码复制/粘贴容错，含截断恢复）。CI 的 `staging.yml` 也跑它；发版前必过。

## 装机测试包 / 开发者 update.json（都不算发布）
`bash scripts/staging_build.sh` → CI 用仓库 Secret 里的真钥匙签名，产出两样：
① Actions 页 Artifacts 里的 `wordsprint-staging-vX.Y.Z`（zip 解压得 apk）；
② 孤儿分支 `dev`（`wordsprint.apk` + `update.json`），手机「设置 → 更新源」填
`https://raw.githubusercontent.com/zhzx2026/wordsprint/dev` 即可用 App 内检查更新覆盖安装。
不建 tag、不建 Release，内置更新源仍是 `releases/latest`；撤销：`git push origin --delete dev`。
本地没有 `wordsprint.keystore` 时 `build.sh` 会**直接失败**（绝不偷偷生成新钥匙——那会让你的老版本装不上、进度全丢）。
要测试包就交给 CI（有仓库 Secret 里的真钥匙）：`bash scripts/staging_build.sh` → Actions 的 **Artifacts** 里下载解压 → 覆盖安装。
**不打 tag、不发 Release**，手机不会收到 OTA。

## 安装
`刷单词-v1.0.2.apk` 为自签名 debug 级证书包：传送到手机 → 允许「安装未知来源应用」→ 安装。
v1.0.1 → v1.0.2 可直接覆盖安装（同签名、versionCode 3），进度全部保留。
